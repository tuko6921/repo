
## 🚀 Running the App

Once your environment is ready, you can launch the dashboard with:

```bash
python app.py
```

By default, Flask will start a development server on `localhost:5000`.

Open your browser and go to:

```
http://localhost:5000
```

You should see the login screen or the dashboard (if already logged in).
